# Healthcare-data-analysis-dashboard
An interactive healthcare data analysis dashboard built with Power BI to analyze healthcare performance, trends, and key performance indicators.

🏥 Healthcare Data Analysis Dashboard

📊 Project Overview

This project presents an interactive Healthcare Data Analysis Dashboard developed to transform healthcare data into meaningful insights that can support data-driven decision-making.

The dashboard provides a visual overview of key healthcare metrics, trends, and performance indicators using interactive charts, tables, and filters.

🎯 Project Objectives

The main objectives of this project were to:

- Analyze healthcare-related data and identify important trends.
- Monitor key performance indicators (KPIs).
- Present complex data in a simple and understandable visual format.
- Identify patterns and areas requiring attention.
- Demonstrate how data analytics and visualization can support decision-making in the healthcare sector.
